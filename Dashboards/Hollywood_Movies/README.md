# Hollywood Movies Dashboard

## Overview
This repository contains a Power BI dashboard that analyzes Hollywood movies based on various dimensions including genre, studio, profitability, and audience reception. It provides valuable insights into industry trends and performance across time.

## Dataset Highlights
The dashboard is built on a clean dataset featuring Hollywood movie data across multiple years with the following characteristics:

- **Genres Analyzed**: 17 unique genres including Comedy, Drama, Action, and Thriller
- **Studios Covered**: Major and independent studios such as Warner Bros, Disney, Universal, and Fox
- **Financial Metrics**: Profitability, Worldwide Gross, and Production Budget
- **Audience Metrics**: Rotten Tomatoes Score and Audience Score

### Top Genres by Volume
1. Comedy (55.6%)
2. Drama
3. Action
4. Thriller
5. Romance

### Studio Contribution
- Independent studios had the highest number of releases.
- Warner Bros. and Disney contributed fewer but high-revenue films.
- 20th Century Fox and Universal consistently produced high-grossing films.

### Release Year Trends
- Peak production years: 2008 and 2010
- Consistent release trends in the late 2000s and early 2010s

### Profitability
- Comedy and Drama led in profitability across all studios
- Independent films showed varied profit margins but high volume

### Audience vs Critic Ratings
- Most ratings aligned closely
- A few genres (e.g., Horror) had high audience engagement but low critic scores

## Dashboard Features
This Power BI dashboard includes:
- Genre and studio-based breakdowns
- Year-wise content trends
- Profitability visualization by genre and studio
- Audience vs critic ratings comparison
- Interactive filters for dynamic exploration
