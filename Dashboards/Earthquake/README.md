#  Earthquake Data Analysis Dashboard

## Overview
This repository contains a Power BI dashboard built as part of a guided project to explore earthquake occurrences worldwide from 1900 to 2014. It visually analyzes trends in magnitude, frequency, depth, and location of earthquakes using interactive elements.

## Dataset Highlights

The dataset includes global earthquake data spanning over a century, with attributes such as:
- **Date Range**: 1900 to 2014
- **Magnitude Types**: mb, mj, ms, Mt, Mw, mwb
- **Location Data**: Generalized place names for each earthquake event
- **Depth & Magnitude**: Key seismic characteristics
- **Total Events**: Over 8,000 recorded earthquakes

## Key Insights

### Earthquake Frequency by Month
- Highest earthquake counts occurred in **June (355)**, **April (354)**, and **May (323)**
- Earthquakes were recorded fairly evenly across all months

### Earthquake Magnitude Distribution
- Most events were in the **6.0–7.0** magnitude range (1,182 earthquakes)
- Significant counts in the **7.0–8.0** range (926 events)
- Magnitudes up to **10.0** were recorded

### Year-wise Earthquake Activity
- Earthquake events steadily increased post-1950s
- Data provides insight into both historical and modern seismic patterns

### Depth Analysis
- Earthquakes varied widely in depth from shallow (0 km) to over 600 km
- Visualization included a histogram of depths and a correlation chart with magnitudes

## Dashboard Features

This Power BI dashboard includes:
- Interactive filter for **Magnitude Type**
- Time sliders to explore earthquakes across specific years
- Visuals for:
  - Earthquakes by month
  - Magnitude histogram
  - Yearly trends
  - Depth histogram
  - Magnitude vs. Depth scatter plot
  - Location-based analysis
