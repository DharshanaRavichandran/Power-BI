# Amazon Prime Content Analysis Dashboard

## Overview
This repository contains analysis of Amazon Prime's streaming content library as of 2021. The analysis is based on data visualized in Power BI Desktop, showcasing key metrics and trends across Amazon Prime's movies and TV shows.

## Dataset Highlights

The platform hosts **9,654 total titles** spanning from 1920 to 2021, with the following characteristics:

- **Content Breakdown**: 
  - Movies: 80.82% (7,810 titles)
  - TV Shows: 19.18% (1,850 titles)

- **Content Diversity**:
  - 25 unique content ratings
  - 518 distinct genres
  - 5,768 different directors

## Key Insights

### Top Genres
1. Drama (986 titles)
2. Comedy (536 titles)
3. Drama, Suspense (399 titles)
4. Comedy, Drama (377 titles)
5. Animation, Kids (356 titles)
6. Documentary (350 titles)
7. Kids (334 titles)
8. Action, Drama (297 titles)
9. Documentary, Special Interest (296 titles)

### Content Rating Distribution
1. 13+ (2,100 titles)
2. 16+ (1,500 titles)
3. ALL (suitable for all ages) (1,300 titles)
4. 18+ (1,200 titles)
5. R (1,000 titles)
6. PG-13, 7+, and PG (each approximately 400 titles)

### Release Year Trends
The majority of content was produced after 2000, showing Amazon Prime's focus on contemporary entertainment, though the library includes historical content dating back a century.

## Dashboard Features
This Power BI dashboard includes:
- Content type distribution
- Timeline visualization by release year
- Genre breakdown
- Content rating distribution
- Key metrics summary

## Getting Started
To explore this dashboard:
1. Clone this repository
2. Open the Power BI file in Power BI Desktop
3. Interact with the visualizations to filter and explore the data
