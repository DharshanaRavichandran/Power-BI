# Amazon Sales Dashboard

## Overview
This repository features an interactive Power BI dashboard that analyzes Amazon product sales across categories, locations, and time. The dashboard visualizes performance metrics such as sales amount, units sold, returns, and reviews. It includes interlinked pages with slicers, tooltips, and dynamic filters to enhance user experience.

This guided project is designed to apply foundational Power BI skills. While it follows a guided structure, key design elements, visual layouts, and interactivity configurations were developed independently.

## Dataset Highlights
The dashboard is powered by two files:
- **Amazon_Sales_Report.xlsx**: The primary dataset containing product-wise and order-level data.
- **Amazon_Fashion.csv**: A reference file mapping product details to categories and subcategories.

Key dimensions and metrics:
- **Product Categories**: Includes apparel, accessories, organizers, etc.
- **Sales Status**: Tracks stages such as shipped, pending, delivered, returned.
- **Geography**: Sales by state and city (e.g., Maharashtra, Delhi, Warje, Pune).
- **Sales Metrics**:
  - Sales Amount
  - Units Sold
  - Return Count
  - Review Count
  - Seller Count
  - Date-wise performance

## Key Insights

### Top Performing States
- Maharashtra and Karnataka lead in total sales.
- High concentrations of sales also seen in Tamil Nadu, Telangana, and Kerala.

### Sales Trends
- Monthly performance tracked from April 2022 to June 2022.
- Peaks observed in May 2022 with 1.63M units sold.

### Product Analysis
- High-performing categories include:
  - Women's Dresses
  - Boys Clothing Sets
  - Bag Organizers
- Return and review counts help evaluate product satisfaction.

### Delivery and Return Metrics
- Status filtering allows analysis by:
  - Shipped
  - Returned to Seller
  - Rejected by Buyer
  - Picked Up
  - Lost in Transit

## Dashboard Features

- **Two Connected Pages**:
  - *Overview Page*: Sales summaries, filters, KPIs
  - *Product Page*: Detailed product performance and review analysis
- **KPI Cards**:
  - Total Sales
  - Units Sold
  - Review Count
  - Return Count
- **Interactive Filters**:
  - Sales Status
  - Product Category
  - Time Range
- **Advanced Interactions**:
  - Page-to-page drill-through navigation
  - Tooltip for enhanced visual context
